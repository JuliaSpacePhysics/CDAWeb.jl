CDAWeb

Julia interface to NASA's Coordinated Data Analysis Web (CDAWeb) for accessing space physics data.

CDAWeb.Dataset — Type
CDAWeb.Dataset(id; direct = false, master_attributes = false)

The CDAWeb dataset id: a CDAS id (AC_H2_MFI), DOI (10.48322/fh85-fj47) or SPASE ResourceID (spase://NASA/NumericalData/ACE/MAG/L2/PT1H); ds[var] is its CDAWeb.Variable.

direct fetches a variable through CDAWeb's subsetting service rather than indexing the whole cached dataset; master_attributes (direct only) takes its attributes from the master CDF. getdata keywords go to get_data_files.

CDAWeb.get_data_files — Method
get_data_files(dataset, variables, t0, t1; fragment_period = Hour(24), kw...)

Get processed data file paths for a dataset + variables within time range (t0, t1).

variables is a name or a collection of names, fetched together into the same files.

Note: usually this is slower than the original files due to CDAWeb's web service processing overhead.

source
CDAWeb.get_data_files — Method
get_data_files(dataset, t0, t1; kw...)

Get original data file paths for a dataset within time range (t0, t1).
